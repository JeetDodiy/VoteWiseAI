# VoteWise AI 🗳️
*Your Vote, Your Voice, Your Future.*

## 🚀 Project Overview
VoteWise AI is an interactive, gamified platform designed to educate first-time voters on the election process. Built for the [Hack2AKill] event.

## 🔑 Key Features
- **Interactive Simulator:** A mock-voting UI to practice the democratic process.
- **AI Learning Assistant:** Personalized guidance on election laws.
- **Civic Pulse Dashboard:** Real-time progress tracking for voter readiness.

## 🛠️ Built With
- React.js
- Firebase (Auth & Backend)
- Tailwind CSS & Framer Motion
- Lucide React

## 💡 How to Run
1. Clone this repo: `git clone [url]`
2. Install dependencies: `npm install`
3. Create a `.env` file with your Firebase credentials.
4. Start the app: `npm start`
